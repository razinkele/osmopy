# Port to shiny 1.6.3 everywhere — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make shiny **1.6.3** the supported version across pyproject, dev `.venv`, CI (incl. docker), and the production deployment, reconciling the deps that drifted in the deploy env.

**Architecture:** A dependency-version promotion — NOT a UI-API migration. The app is already 1.6-compatible (e2e 50/50 under 1.6.3). Lift the `shiny<1.6` cap; bump `shinyswatch>=0.11` (its bundled Bootstrap 5.3.8 matches shiny 1.6.3 → precompiled theme, no libsass); bump `shinywidgets>=0.7`; declare `cma>=4.0` (numpy-2 fix); pin `shiny_deckgl @v1.9.2` (matches prod's `layer_legend_widget` path). Validate on a CLEAN venv, then roll out.

**Tech Stack:** Python 3.12/3.13, shiny 1.6.3, shinyswatch, shinywidgets, shiny_deckgl, cma, pytest, pip.

**Spec:** `docs/superpowers/specs/2026-06-15-port-shiny-1.6-design.md` (converged, 3 review rounds).

**Prerequisites (already DONE on origin/master):**
- CI green — undeclared-dep failures fixed (`6fa0769` copernicus guard, `003336c` httpx in `[dev]`).
- `razinkele/shiny_deckgl` tag **`v1.9.2`** pushed (commit `c47b330`), pip-resolvable.

**Branch:** `feat/port-shiny-1.6` (rebased on green master; holds the spec + this plan). Do NOT start on master.

### Task 4: Make `deploy.sh` version-aware

**Files:**
- Modify: `deploy.sh` (Step 2 block, lines ~110–124)

**Why:** the current loop is presence-only (`if ! pip show "$pkg"`) — it installs only ABSENT packages and cannot enforce a minimum version, so bare names for already-present packages (cma/shinyswatch/shinywidgets) would never upgrade.

- [ ] **Step 1: Replace the Step 2 dependency block.**

Find this exact block:

```bash
# --- Step 2: Install missing Python dependencies ---
MISSING_PKGS=()
for pkg in pymoo SALib; do
    if ! "$SHINY_PIP" show "$pkg" &>/dev/null; then
        MISSING_PKGS+=("$pkg")
    fi
done

if [[ ${#MISSING_PKGS[@]} -gt 0 ]]; then
    info "Installing missing packages: ${MISSING_PKGS[*]}"
    "$SHINY_PIP" install "${MISSING_PKGS[@]}" --quiet
    info "Packages installed."
else
    info "All Python dependencies already installed."
fi
```

Replace with:

```bash
# --- Step 2: Install missing + version-floored Python dependencies ---
# Presence-only check for packages we just need installed:
MISSING_PKGS=()
for pkg in pymoo SALib; do
    if ! "$SHINY_PIP" show "$pkg" &>/dev/null; then
        MISSING_PKGS+=("$pkg")
    fi
done
if [[ ${#MISSING_PKGS[@]} -gt 0 ]]; then
    info "Installing missing packages: ${MISSING_PKGS[*]}"
    "$SHINY_PIP" install "${MISSING_PKGS[@]}" --quiet
fi

# Version-floored packages: a presence check cannot enforce a minimum, so upgrade
# unconditionally. cma <=3.3.0 breaks under numpy 2; shinyswatch <0.11 forces a sass
# compile under shiny 1.6.3; shinywidgets floor raised. shiny_deckgl must match prod's
# layer_legend_widget API (v1.9.2).
info "Ensuring version-floored packages (cma, shinyswatch, shinywidgets, shiny_deckgl)..."
"$SHINY_PIP" install --quiet --upgrade "cma>=4.0" "shinyswatch>=0.11" "shinywidgets>=0.7"
"$SHINY_PIP" install --quiet --upgrade "shiny_deckgl @ git+https://github.com/razinkele/shiny_deckgl.git@v1.9.2"

# Fail loudly if any floor is unmet after install.
"$SHINY_PIP" install --quiet "packaging" || true
"${SHINY_PIP%pip}python" - <<'PYCHK'
import sys
from importlib.metadata import version
from packaging.version import Version
floors = {"cma": "4.0", "shinyswatch": "0.11", "shinywidgets": "0.7", "shiny": "1.6.3", "shiny_deckgl": "1.9.2"}
bad = []
for pkg, floor in floors.items():
    have = version(pkg)
    if Version(have) < Version(floor):
        bad.append(f"{pkg} {have} < {floor}")
if bad:
    print("DEPENDENCY FLOOR CHECK FAILED:", "; ".join(bad)); sys.exit(1)
print("dependency floors OK:", {k: version(k) for k in floors})
PYCHK
info "Python dependencies ensured."
```

- [ ] **Step 2: Shellcheck / bash syntax check.**

Run: `bash -n deploy.sh`
Expected: no output (syntax OK). (`${SHINY_PIP%pip}python` derives the interpreter next to pip; if `deploy.sh` already defines a `$SHINY_PYTHON`-style var, use that instead — check the top of the file and prefer the existing variable.)
