# OSMOSE 4.4.0 Jar Swap + Value Migration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bundle the OSMOSE 4.4.0 jar, make OSMOPY write native 4.4.0 configs with value migrations that preserve engine behavior (the 4.4.0 larval-mortality units change), validate via A/B against the 4.3.3 jar, then make 4.4.0 the default engine (keeping the 4.3.3 jar in place as rollback insurance — a version-aware selector picks 4.4.0).

**Architecture:** A value-migration layer scales the larval-rate keys at the I/O boundary (×ndt writing native 4.4.0, ÷ndt reading a native-4.4.0 config). The internal model holds the **authored** value, which the Python engine applies as a once-per-cohort total (`osmose/engine/processes/natural.py:139` — NOT divided by ndt); the 4.4.0 Java engine pre-divides by `nStepYear` at load, so writing `×ndt` cancels that to reproduce the authored effective mortality. CRITICAL: the transform needs both `simulation.time.ndtperyear` AND the rate key present in the SAME dict, so it runs on the **aggregated/full** config (write: in `to_target_keys`, which gets the full dict; read: in `reader.read()` AFTER sub-files are merged) — NOT in per-file `canonicalize_config` (a sub-file lacks the ndt key). Phases: A = value layer (CI-testable), B = fetch jar + A/B validation gate (local), C = cutover, D = deploy + docs.

**Tech Stack:** Python 3.12, pytest, OSMOSE Java jar (subprocess). Run with `.venv/bin/python`.

**Spec:** `docs/superpowers/specs/2026-06-18-jar-swap-4.4.0-design.md` (approved). Built on PR1 (`001c530`) + PR2 (`dc2d701`).

**SHIP AS TWO PRs (in-loop review recommendation):** **PR-A = Tasks 1–3** (value-migration layer + guards + version hardening) — pure, CI-testable, jar-independent, provably parity-safe (it changes only the explicit-`4.4.0` path; the write-default stays `4.3.3` until Task 7), shippable immediately. **PR-B = Tasks 4–12** (fetch jar, A/B gate, cutover, deploy, docs) — opened only AFTER the Phase B A/B validation passes locally. This de-risks the network/Java-availability block and keeps the dangerous default-flip + JAR_PATH change together behind the gate.

## Task 1: Larval-rate value migration (the core transform)

**Files:** Modify `osmose/config/aliases.py`, `osmose/config/reader.py`; Test: `tests/test_config_migration_440.py`

**Why read-side lives in `reader.read()`, not `canonicalize_config`:** the transform needs `simulation.time.ndtperyear` AND `mortality.additional.larva.rate.spN` in the same dict. PR2 calls `canonicalize_config` PER FILE in `read_file`, and those two keys live in DIFFERENT sub-files (simulation vs additional-mortality), so a per-file call can never see the ndt → it would skip (and a multi-file native-4.4.0 re-import would leave the rate un-divided and compound 24× on the next write). So: `canonicalize_config` does KEY renames only (unchanged from PR2); the read-side ÷ndt runs ONCE in `reader.read()` on the fully-merged dict, gated on the master `osmose.version`. The write-side ×ndt runs in `to_target_keys`, which always receives the full dict. (Scenario/in-memory loads already hold the authored value — they don't go through `reader.read()` file-parsing — so they correctly need no read-side migration.)

```python
import re
import warnings

# Larval additional-mortality SCALAR per-species rate. The OSMOPY internal model and the Python
# engine apply this value as a once-per-cohort TOTAL (osmose/engine/processes/natural.py:139 —
# NOT divided by ndt). 4.4.0 Java reinterprets the config value as rate/YEAR and pre-divides by
# nStepYear at load (AnnualLarvaMortality.init() adds `/ nStepYear`). So to reproduce the authored
# effective mortality on the 4.4.0 jar, multiply by ndtperyear on write (cancels the jar's ÷ndt);
# divide by ndtperyear when READING a native-4.4.0 config back to the authored value. Matches ONLY
# `...rate.spN` (NOT the `.bydt.file.spN` path variant nor `.seasonality.file.spN`).
_LARVA_RATE_RE = re.compile(r"^mortality\.additional\.larva\.rate\.sp\d+$")
_NDT_KEY = "simulation.time.ndtperyear"


def _ndtperyear(cfg: dict[str, str]) -> float | None:
    raw = cfg.get(_NDT_KEY)
    if raw in (None, ""):
        return None
    try:
        return float(raw)
    except ValueError:
        return None


def _scale_rate_value(value: str, factor: float) -> str:
    # ';'-separated per-stage arrays are scaled component-wise; :.10g trims float noise.
    return ";".join(f"{float(p) * factor:.10g}" for p in value.split(";"))


def _migrate_larva_rate(cfg: dict[str, str], factor: float, *, warn_bydt: bool) -> dict[str, str]:
    """Scale per-year larval-rate scalars by `factor` (ndt to write 4.4.0, 1/ndt to read it)."""
    result = dict(cfg)
    has_larva = any(_LARVA_RATE_RE.match(k) for k in result)
    if has_larva and _ndtperyear(result) is None:
        warnings.warn(
            "larval additional-mortality rate present but simulation.time.ndtperyear is missing; "
            "skipping the 4.4.0 per-year unit migration (config may be mis-scaled for the jar).",
            stacklevel=2,
        )
        return result
    for key, value in list(result.items()):
        if _LARVA_RATE_RE.match(key):
            result[key] = _scale_rate_value(value, factor)
        elif warn_bydt and key.startswith("mortality.additional.larva.rate.bydt.file"):
            warnings.warn(
                f"{key} references a per-time-step larval-rate file that 4.4.0 reads as rate/year; "
                "OSMOPY does not rescale the referenced file — verify it manually.",
                stacklevel=2,
            )
    return result
```

```python
def _drop_4_4_0_removed_keys(cfg: dict[str, str]) -> dict[str, str]:
    """Drop keys that 4.4.0 removed or reinterprets, to preserve legacy behavior on write."""
    result = dict(cfg)
    # 4.4.0 removed the species.lmax growth cap (no clean migration; documented limitation).
    for key in [k for k in result if k == "species.lmax" or k.startswith("species.lmax.")]:
        del result[key]
    # 4.4.0 species.beta feeds the predation allometric exponent (default 1 == legacy). 4.3.3 read
    # it only under bioen; for a non-bioen config it must not be emitted.
    bioen_on = str(result.get("module.bioenergetics.enabled", "false")).lower() == "true"
    if not bioen_on:
        for key in [k for k in result if k == "species.beta" or k.startswith("species.beta.")]:
            del result[key]
    return result
```

```python
import re as _re

def _pick_default_jar(jars: list[Path]) -> Path | None:
    if not jars:

    return max(jars, key=lambda p: (_ver(p), p.name))
```
